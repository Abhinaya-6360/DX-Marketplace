# Creator visual language (web)

This skill is the web entry point to CDS 2.0. It holds no values of its own, so the two can
never disagree.

1. Find the **creator-design-system** skill in this plugin (it's listed with the available
   skills, with its location).
2. Read its `SKILL.md`, then `references/brand-rules.md` and `references/web.md`.
3. Build with its `design-system/tokens.css` and `assets/logos/`, and finish with its
   `references/brand-check.md`.

Web output is a reviewable HTML draft for design and dev, never production code.
